# 金牌得主 S2

《金牌得主 S2》是改编自つるまいかだ创作的同名漫画的花样滑冰运动动画，由 ENGI 制作。

故事讲述未能实现选手梦想的青年明浦路司，与渴望站上冰场的少女结束祈相遇，并成为她的教练。第二季中，结束祈升入新手A组，迎来了争夺全日本锦标赛出场资格的中部街区大赛。面对自幼在名门俱乐部接受训练的精英选手们，结束祈与司将携手迎战强敌，向冰上的最高荣耀发起冲击。
