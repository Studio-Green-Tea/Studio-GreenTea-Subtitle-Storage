# 沉默魔女的秘密

《沉默魔女的秘密》是一部奇幻校园动画，改编自依空まつり创作的同名轻小说作品。

故事围绕莫妮卡·埃瓦雷特展开，她作为里迪尔王国"七贤人"中最年轻的成员，是史上第一位能够使用"无咏唱魔术"的天才魔女。然而本性极度怕生的她，平日里只与黑猫使魔隐居深山、埋头研究。某日，她接到国王的密令——潜入贵族云集的名门学校赛莲蒂亚学园，执行保护第二王子的绝密任务。生性羞怯的天才魔女，不得不隐瞒身份，在暗中制裁接近王子的恶人，展开一段充满意外与挑战的奇幻冒险。
