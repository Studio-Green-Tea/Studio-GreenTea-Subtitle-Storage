# 公主大人，接下来是"拷问"时间 S2

《公主大人，接下来是"拷问"时间 S2》是改编自春原罗宾逊原作、ひらけい作画同名漫画的搞笑奇幻动画，由 PINE JAM 制作。

故事讲述人类皇国军的公主被魔王军俘虏后关押在地牢之中，首席拷问官对她施加各种"酷刑"——刚出炉的蓬松吐司、热气腾腾的拉面、可爱的小动物与温暖人心的陪伴。第二季中，全新一轮又一轮令人难以招架的"拷问"接踵而至，公主的牢狱生活变得愈发幸福，而她泄露的情报却依旧毫无用处。
