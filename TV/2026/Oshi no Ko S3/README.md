# 【我推的孩子】S3

《【我推的孩子】S3》是一部以演艺圈为舞台的悬疑动画，讲述了星野爱久爱海与星野瑠美衣兄妹在娱乐界追寻真相的故事。

第三季以"丑闻篇"为核心，加奈遭遇媒体丑闻危机，阿库亚为保护她做出惊人抉择，同时揭开了关于星野爱死亡的更多真相，复仇之路进入白热化阶段。
