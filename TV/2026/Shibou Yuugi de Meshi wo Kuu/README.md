# 以死亡游戏为生

《以死亡游戏为生》是一部融合死亡游戏与美食元素的悬疑动画，讲述了17岁的职业死亡游戏玩家反町友树在致命挑战中求生的故事。

作品以独特的视角展现了主角在各种生死攸关的游戏中，不仅要运用智慧和策略活下去，还要在极端环境下享受美食的奇妙日常。
